# 分享与导出

## 文字转图分享

把楼层正文或书推荐做成一张可以直接发出去的图片。

入口有三处：

| 入口 | 内容 |
| --- | --- |
| 帖子详情（分享扫书） | 当前楼层正文 |
| 书聚合页 | 该书的多条推荐拼接 |
| 我的 | 自由模式，内容自己填 / 自己挑 |

可调参数：

- **字号**：8 – 30
- **行距**：1.0 – 3.0
- **配色**：白 / 黑 / 绿 / 米 四种（边框与文字色随配色联动，正文对比度 ≥ 4.5:1）
- **水印**：默认 `扫书汇APP | BY <推荐人>`，可以改成任何文字

导出为 **2.5 倍像素**的 PNG，保存到相册或用系统分享面板发给别人（Windows 上直接存文件）。

## 书单导出（Markdown / TXT）

收藏夹、书聚合页、搜索结果三处都有「导出」入口，把当前这批书渲染成文档：

- **Markdown**：书名 + 作者 + 推荐/排雷条数 + 日期 + 摘要，适合贴到 Notion / Obsidian / 论坛；
- **纯文本**：适合直接发聊天窗口。

导出只会写进**当前页面已经加载的那批结果**，字段缺失时留空，不会为了凑格式编造数据。
