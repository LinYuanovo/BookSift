# 搜索与五维筛选

## 关键词搜索

在搜索框里输入书名、作者或正文关键词，回车提交。

- **3 字及以上**：走 FTS5 全文索引（trigram），秒级返回并给出命中总数；
- **2 字词**：FTS 无法有效取词，自动降级为 `LIKE` 模糊匹配，界面会提示「已降级为慢速搜索」，结果依然完整；
- 多个关键词用空格分隔，**全部命中**才算一条结果。

搜索台还提供两个免费的入口：

- **联想**：输入即出，最多 8 条书名候选（输入 1 个字就会触发）；
- **搜索历史**：每条都保留完整条件摘要（关键词 + 五维 + 排序），点一下直接复现当时的结果；左滑删除，长按复制关键词。

## 五维筛选

搜索框下方是五个维度的筛选 chips，每个维度都是「点开 → 选值 → 立即生效」：

| 维度 | 取值 |
| --- | --- |
| **年** | 全部 / 各年份 / 更早 |
| **月** | 全部 / 1–12 月 |
| **旬** | 全部 / 上旬（1–10 日）/ 中旬（11–20 日）/ 下旬（21 日及以后） |
| **来源** | 全部 / 各个吧与渠道（含 `自采`） |
| **类别** | 全部 / 扫书 / **排雷** / 求书 / 日常 |

几个要点：

- 每个候选值后面都带**真实命中计数**，而且是**联动**的 —— 选了 2024 年之后，月份候选的计数就只反映 2024 年的数据，不会出现「点了是 0 结果」的假选项；
- 多个维度之间是 **AND 交集**（2024 ∩ yy小说吧 ∩ 排雷），同维度内是单选；
- 筛选条件会随搜索历史与书签一起被快照保存，之后可以一键复现；
- 想从头来过，用 chips 行右端的清除（或把每个维度拨回「全部」）。

## 结果页

结果有两个 Tab：

- **书级**（默认）：按书归并 —— 书名 + 作者 + 推荐条数 + **排雷条数**（红色计数，有点击过滤功能）+ 最近日期 + 命中片段高亮 + 渠道徽标集合；
- **帖级**：帖子粒度 —— 标题 + 楼层摘要 + 作者 + 日期 + 类别徽标，点击进帖子详情，并**带着当前搜索词做正文高亮**。

结果区右上角还有两个动作：

- **排序**：时间 ↓（默认）/ 时间 ↑；
- **目录**：把当前已加载的结果行拉成一个清单，直接跳到某一条，不用一直往下滚。

翻页是**上滑无限加载**，每页 40 条；命中总数超过 5000 时显示 `5000+`。

::: tip 反过来也行
书聚合页、帖子详情里的书名都是可点的 —— 点一下就等于用这个书名重新搜一次。这是「顺着一条推荐找到同类书」最常用的路径。
:::

## 导出这一次的搜索结果

结果区可以「导出书单」，把当前结果渲染成 Markdown / TXT 文档保存或分享，见[分享与导出](/guide/share)。

## 贴吧在线搜索

本地库里没有的内容，去结果页顶部的 **贴吧在线** Tab：

- 只有你手动提交时才发**一次**请求，不会自动翻页或轮询；
- 结果支持按**相关度 / 时间**重排（纯客户端排序）；
- 整卡点击进入**在线帖子页**，按时间序渲染楼层（与离线详情页同一套富文本 / 图片组件）；
- 在线内容**只读不落库**，离页即弃；卡片右上角的按钮可以直接跳到贴吧原帖（手机上有贴吧 App 就唤起 App，否则走浏览器）。

在线搜索走的是贴吧的非公开接口，可能随时失效；本地搜索永远不受影响。
