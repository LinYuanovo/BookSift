# 书聚合页与帖子阅读

## 书聚合页

书聚合页是把**所有推荐过同一本书的帖子聚到一处**的页面，也是这个 App 最核心的一页。从首页卡片、搜索结果的书级卡、榜单行或收藏夹都能进。

页面结构：

- **头部**：书名大标题 + 作者 + **推荐次数 / 排雷次数对比**（两个计数都可点，点了就等于「只看这一类」）；
- **语义筛选 chips**：按推荐 / 排雷 / 渠道再收一层，条件会写进 URL 快照，可以分享也可以回退；
- **评价卡列表**：每条 = 推荐人 + 日期 + 渠道 + 推荐语摘要，点开直接落到**对应帖子的对应楼层**；
- **动作**：收藏、加书签、导出这本书的全部推荐（Markdown / TXT）、复制原帖链接。

::: tip 关于溯源
帖子带 `tid` 的条目可以复制原帖链接跳回贴吧；没有链接的条目会如实显示「原帖已不可溯源」，不会给你一个点不开的假链接。
:::

## 帖子详情页

帖子详情按**时间序**渲染楼层，富文本排版尽量保留原帖样式（加粗、链接、引用、图片）。

- **楼层目录**：底部（或顶部）的目录弹层列出全部楼层，点一下就跳到那一层，长帖不用手滑；
- **图片**：点图放大查看，同一楼的多张图可以左右切换；
- **书名可点**：正文里的《书名》点击等于用该书名再搜一次，长按可以复制；
- **原帖外链**：标题栏的按钮直接打开贴吧原帖 —— Android 上优先唤起贴吧 App，没装则走浏览器；
- **加书签**：把**当前搜索条件 + 阅读楼层位置**一起存下来，下次从书签夹一点就回到原位；
- **分享扫书**：把当前楼层正文生成分享图，见[分享与导出](/guide/share)。

### 自由复制

想手动抄一段正文时，长按正文（或点 AppBar 上的选择入口）进入**选择模式**：每个楼层都变成可选对象，勾选后一次复制多楼，同时保留原来的横滑翻页手势。

## 我的：收藏夹 / 书签夹 / 搜索历史

「我的」页把三件事放在一处，三个列表都是**实时**的（写入即刷新）：

| 入口 | 内容 |
| --- | --- |
| **收藏夹** | 书与帖子两种粒度分 Tab 展示，默认按添加时间倒序，可切成按书名排序；左滑删除 |
| **书签夹** | 每条书签 = 一组搜索条件快照 + 一个楼层位置，点一下**完整复现当时的搜索并滚回该楼层** |
| **搜索历史** | 最近 50 条搜索条件，可整条复现，也可一键清空 |

页面下方是**设置**与**关于**入口（版本号、检查更新、数据来源署名、免责声明全文）。

## 常见的几条路径

- **想看看某本书被推荐得多不多** → 首页或搜索结果点书名 → 聚合页看推荐 / 排雷计数对比 → 点排雷计数只看雷点；
- **想顺着一个人找书** → 帖子详情里点推荐人名，等于按这个名字再搜一次；
- **读到一半被打断** → 加书签 → 下次从书签夹点回来，条件和楼层都在；
- **想留个书单给别人** → 聚合页或搜索结果导出 Markdown / TXT。
