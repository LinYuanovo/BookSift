# 采集中心

内置种子包是**一次性快照**（数据截至日在「我的 → 关于」里能看到）。想拿到快照之后的新帖，用采集中心自己增量采集。

采集是这个 App 里**唯一会持续发网络请求**的功能，所以默认参数都压得很保守。

![采集中心](/shots/05-collect.png){.shot-phone}

## 关注吧

出厂自带两个活跃渠道：**yy小说吧**、**哀伤雪刃**。每个吧一张卡片，显示：

- 启用开关；
- **水位**：这个吧已经采到哪一页（前缀水位续采，下次从上次的位置往后接着拉，不重复从前翻）；
- 上次结果（新增条数 / 失败原因）；
- 失败冷却倒计时（见下文熔断）。

点「添加吧」输入吧名即可新增，会先验证这个吧是否存在再落库。

## 立即采集

点「立即采集」开始，进度页分四步走：

1. **拉帖列表**：按吧并发拉取帖子列表页（`pn/总页` 进度）；
2. **解析楼层 + 分类**：逐帖解析楼层、跑 v3 分类器判定推荐 / 排雷（按 tid 显示进度）；
3. **入库 / 建索引**：写入本地库并更新全文索引；
4. **完成汇总**：`+N 帖 / +M 楼层 / +K 书目 / 跳过 X 重复 / 丢弃 D 闲聊`。

采集可以随时取消：**水位只在成功批次之后推进**，所以中断、杀进程、断网之后再采都不会产生重复数据，也不会漏掉该采的页。

日志区保留最近 200 条运行记录（采集过程中逐条输出，不裁剪）。想机读完整日志，用 headless CLI 的 `logs` 子命令导出，见 [Headless CLI 与 API](/development/headless)。

## 频控：三重约束

采集侧内置三条硬约束，与代码常量同源（「我的 → 关于」里也会按当前常量如实列出）：

| 约束 | 当前值 | 说明 |
| --- | --- | --- |
| 全局请求间隔 | **1.5 – 3.0 秒**随机 | 跨吧共享同一个限速器，不是每个吧各算一份 |
| 每日请求预算 | **≤ 300 次**（匿名档） | 用满即停，次日恢复 |
| 失败退避 | 单帖 30/60/120 秒重试，最多 3 次 | 帖子级重试，不影响其它帖子 |
| 熔断 | 单个吧连续失败 3 次 → 冷却 **48 小时** | 冷却期内该吧不再发请求，其余吧继续 |

## 并发

跨吧并发默认 **2**，上限 **3**（设置页可调）。往高调会提高单位时间请求数，风控风险也同步上升 —— 设置页里对这一项有显式提示，建议保持默认。

## 仅 WiFi 采集（默认开）

移动网络下不会开始采集，避免偷跑流量，也顺带降低被风控盯上的概率。

## 关于账号

**当前版本全程匿名**：不采集、不存储任何账号凭证。界面上关于 BDUSS 的说明只是告诉你「导入可以提配额（暂未提供）」—— 没有假入口，也不会偷偷存 cookie。

## 采集之后

- 首页顶部会出现「自采新内容 +N 条」，点进去看新增了什么；
- 想把范围收窄成「只看自己采的」，在搜索页把**来源**维度选成 `自采`；
- 自采数据同时会影响榜单的「本月 / 近 30 天」计数。

::: warning 请低频使用
采集走的是贴吧非公开的逆向接口，不是官方 API。接口随时可能变更或失效，高频、长时间采集存在被风控的风险。请按需增量采集，不要把它当成爬虫来跑。详见[数据来源与合规](/guide/data)。
:::
