# 导入扫书与编辑帖子

## 导入

首页或采集页右上角点「导入扫书」。支持三种入口：

- 粘贴论坛、社区、公众号正文，再点「识别并校对」。
- 输入公开网页的完整链接，点「读取链接」。遇到来源验证，请在实际浏览器完成验证后保存 HTML，或粘贴正文。
- 选择 TXT、Markdown、HTML、DOCX 文件。文本文件使用 UTF-8 或 UTF-16 编码。

校对页区分「发帖人 / 书评人」和每本书的「小说作者」。支持多书文档，识别书名号、书名标签和书名 + 作者格式。请核对候选书目、作者、评价段落和推荐 / 排雷分类；误识别的书目可以移除，遗漏的书目可以手动添加。

未识别出书目仍能保存为帖子，原文不会丢弃。之后打开该帖子编辑，可补充书目并进入书级搜索和聚合。

## 原文与图片

- 入库完整保存原始文件字节，可在编辑页导出原始留档；编辑原文不会改写初次留档。
- HTML 提取正文文本、链接、图片及说明；DOCX 的正文与内嵌图片一起入库。原格式与排版保存在原始文件中，阅读页沿用项目的楼层与图片展示。
- 网络图片保存时尝试下载并嵌入，下载失败明确提示，用户可以保留链接继续保存或返回补充图片。只保留链接的图片不承诺离线可用。
- 视频、音频或无法展示的资源保留文字提示及原始文档，不把这些内容算作已完整展示。
- 验证页、失效页、空正文和无法无损解码的文件不会被当成成功导入。

单文档上限 24 MB，DOCX 解压内容及嵌入图片上限 64 MB；建议长书单分篇保存。

## 统一编辑

任意本地帖子详情的「更多」→「编辑帖子」，包括内置帖子、采集帖子与手动导入帖子。

共用同一编辑页：标题、发帖人、来源、栏目、发布日期、原文链接、类别、全部楼层正文及图片、书名、小说作者、完整评价、推荐人、评价日期、来源、小说字数和评级。

保存后同步首页、搜索、书级聚合与收藏 / 书签展示。原始帖子、保留的楼层和书目 ID 不变；本地编辑不会被后续重新采集、分类维护或种子升级覆盖。重新识别书目会替换本次书目校对内容，因此先确认；取消编辑会提示未保存修改。

同一原文和来源重复导入会打开既有帖子，不重复增加推荐次数。不同帖推荐同一本书仍合并到同一书页。
