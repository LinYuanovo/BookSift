# 四来源搜索与应用内论坛流程

## 行为

- 搜索页的同一分段控件包含本地库、贴吧在线、尚香书苑、搜书吧。提交后收成当前来源按钮；点该按钮再次展开。展开时隐藏清除/确认，目录常驻，结果列表不因控件展开而卸载。动效使用 AppMotionTheme 的 switch/enter/exit，减弱动效下取消尺寸动画。
- 论坛设置支持账号/邮箱、密码、Cookie。账号密码和 Cookie 通过 SecretStore 存本机安全存储，数据库仅存论坛地址。地址变更不复用旧地址的机密；旧 Cookie 格式仍可读取。
- 论坛地址可省略协议；保存或验证时自动补全 HTTPS、清除首尾空白并保留端口/子路径。省略前缀仍按补全后的 origin 判断，不误清同站 Cookie。
- 已有 Cookie 时直接搜索；服务器明确要求登录才触发一次应用内登录及重试，网络故障不自动重复登录。保存账号密码时先验证现有会话，失效后打开内嵌登录。验证码保留给用户填写，未完成不自动提交。
- 论坛结果先进入应用内帖子网页；可以在原页面阅读、处理权限、人工确认购买/回复，再选附件。下载显示进度、可取消，完成后调用系统保存对话框，取消保存不报告成功。付费、回复、验证码均不由 Agent 自动操作。
- 内嵌页面限制当前 HTTPS origin，账号填充脚本再次验证页面和表单 origin；不打开外部浏览器。网站正文保持站点样式，应用导航、状态、输入与弹窗使用项目 token。
- Android/iOS/macOS/Windows 使用原生 WebView。Linux 没有稳定版插件后端，当前提供明确的不支持提示，保留 Cookie 搜索；不能将此称为 Linux 完整登录/阅读支持。

## 验证范围

自动回归包含来源切换/结果保留、320/390/1280 宽度、深浅色和放大字体设置弹窗、Cookie 旧格式/地址隔离、有效会话复用、过期单次重登、网络错误不重登、下载/保存取消。

`integration_test/forum_webview_test.dart` 使用原生 Android WebView 和无机密的内存 HTML 验证账号填充、验证码停留、提交及 Cookie 回收；它不代表真实账号登录通过。生产站公开登录入口通过 playwright-cli 查看，未使用任何用户账号、Cookie 或购买权限。

新增 `flutter_inappwebview` 6.1.5。Android 最低版本保持 24，Windows 需要 WebView2 Runtime；不修改系统默认浏览器。
