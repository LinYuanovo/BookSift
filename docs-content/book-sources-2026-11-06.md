# 尚香书苑与搜书吧接入

## 使用

搜索页右上角「书源搜索与下载」，或书籍详情页「搜索下载本书」，进入独立的书源搜索页。

1. 选择书源，打开「书源设置」。
2. 从导航页解析最新地址，或填写已确认的 HTTPS 论坛首页地址。
3. 需要账号时，在浏览器登录并将 Cookie 保存到该书源。Cookie 只进入系统安全存储，并绑定论坛 origin；换域名必须重新登录。
4. 搜索书名，点击结果选择附件；下载完成后通过系统文件对话框选择保存位置。Android 使用系统文档提供器，Windows 使用保存文件对话框。
5. 可取消下载或取消保存。临时文件会删除，不留下半成品。单个附件上限 64 MiB；更大文件、站外下载、购买/回复/验证码等步骤使用原帖浏览器入口。

## 初次现场调查（2026-11-06，已由追加实测补充）

- `https://sxsy.pw/` 导航页的 `#enterButton` 指向 `https://sxsy33.com`，访问后跳转登录页。没有使用用户账号，未验证登录后的真实搜索/下载。
- `https://soushu2025.com/` 在当前网络出现证书信任失败；HTTP 导航跳到 `tianyuan999.com:6677` 的 404 页面，无法取得可确认的 HTTPS 论坛最新地址。应用不会忽略 TLS 错误，允许用户提供正常地址。
- 两站参考实现均走 Discuz `search.php?mod=forum`，先 GET 获取 `formhash` 再 POST `srchtxt`，附件走 `forum.php?mod=attachment` / `attachment.php`；未找到可直接使用的公开官方 API。
- 搜书吧历史页面使用 GBK，编码由响应头/meta 判断，搜索表单按同一字符集编码。

## 参考与实现边界

- [Aur5411/SXSY](https://github.com/Aur5411/SXSY)：Android Discuz 客户端。
- [Aur5411/soushu](https://github.com/Aur5411/soushu)：搜书吧 WebView 客户端。
- [Foolllll-J/astrbot_plugin_soushuba](https://github.com/Foolllll-J/astrbot_plugin_soushuba)：参考 `core/search_service.py`、`url_resolver.py`、`download_service.py` 的请求协议和选择器；本项目独立实现 Dart 适配器，没有复制其业务代码。

不继承参考项目关闭 TLS 校验或自动支付的做法。搜索请求使用当前确认的 origin，重定向到其他 origin 时不携带或转发凭证，报错后交由用户确认最新地址。付费/回复附件不自动操作。

自动测试覆盖导航链接筛选、结果/附件去重、GBK 表单、Cookie origin 绑定、登录页报错、附件字节与伪 HTML 响应、320px 页面布局。以上属于受控模拟响应测试，不代表现场登录态下载成功。

## 追加真实账号测试（2026-11-06）

用户授权两站测试账号登录，并要求搜书吧同时测试直连与多个代理节点。测试使用独立浏览器会话、独立 Mihomo 进程和 17991–17994 端口，候选香港、日本、新加坡、美国节点。未调用主代理控制器切换节点，也未写入主代理配置。

- 尚香：从 `sxsy.pw` 进入 `sxsy33.com`，邮箱登录及页面验证码完成，确认登录成功。浏览器搜索《红楼梦》显示57条，生产 `ForumSourceClient.search` 使用同一登录态成功获取首批20条。
- 搜书吧：2025/2030 导航 HTTPS 证书失败、部分 HTTP 路线转发失败；日本与新加坡测试节点通过 `soushu2022.com` 到达 HTTP 中转页。中转页返回404，但 HTML 中确实含有“搜书吧/最新地址”链接，最终到达 `https://nyt6y.bew2459m.com/`。取得地址后，直连、新加坡和美国节点也能打开论坛首页；主要故障在动态导航链，不能概括为论坛只能走代理。
- 搜书吧真实账号登录成功，浏览器搜索《西游记》显示128条。生产 Dart 适配器通过日本独立代理成功取得首批50条，GBK 编码正常。
- 生产 Dart 导航解析在真实网络中完成 `200 / → 200 /book/ → 404 /o/ → HTTPS论坛搜索页验证`，返回正确当前地址；不将动态域名硬编码进应用。
- 尚香帖子存在 `_dsign` 跳转壳。修复前仅收到约2–3KB脚本并误报无附件；修复后静态解析限定的字符串表达式，成功获取约39–55KB实际帖子。支持函数返回字面量/参数、拼接及 location 的 href/replace/assign；限制深度、步数、长度和同域同帖路径。**不运行任意 JS，不发起脚本中的其他操作。**
- 付费附件现明确提示先在原帖确认购买，避免和网络/解析失败混为一谈；“下载”按钮与文件名分开的 Discuz 布局已兼容。

### 可复现工具

`app/tool/check_live_book_source.dart` 通过参数读取私有浏览器 state 文件，调用生产适配器；可用 `BOOKSIFT_TEST_PROXY=127.0.0.1:<port>` 指定独立测试代理。工具不内置账号密码，不输出 Cookie。原始响应诊断仅在显式设置 `BOOKSIFT_TEST_DIAGNOSTICS` 时落到指定临时目录，测试结束必须删除这些文件。
