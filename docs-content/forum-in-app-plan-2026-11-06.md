# 搜索来源整合与应用内书源流程

本轮在当前工作区继续实施，保留此前尚未提交的发布清单与更新器改动。

1. 四个来源复用搜索页同一个分段控件；选择来源时收起清除/确认，目录与结果保留；搜索提交后收起来源选择并恢复动作。动画使用 AppMotionTheme，兼顾窄屏、大字体和减弱动效。
2. 书源设置支持账号密码或 Cookie，凭证只存 SecretStore 并绑定 origin。有效会话复用；明确失效才打开应用内登录，自动填入已保存账号密码并尝试登录，验证码由用户在应用内填写。
3. 应用内网页视图承载论坛帖子、登录、验证码及站内权限处理；读取当前帖子附件后进入应用下载、取消和系统文件保存。不开外部浏览器，禁止跨域自动带凭证、自动支付或自动回复。
4. 测试搜索交互与 token、凭证持久化/失效处理、登录脚本与导航约束、下载保存取消；执行全量 Flutter 回归、静态分析和 Android 构建/原生检查。实站凭证不可用时如实记录验证边界。
