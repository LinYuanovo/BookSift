# 启动、空间、阅读恢复、字数与书源计划

日期：2026-11-06。基线：`31dc9ac`（v1.0.3+4）。分支：`codex/performance-session-sources`。

## 约束与验收

- 在独立工作树实现，不改主工作区；按完整功能本地提交，不推送、不发布。
- 不读取或改写用户真实书库；复制内置种子和测试库测量迁移、启动与空间。
- 先定位阻塞首屏的数据库、字体、种子与查询成本，再优化；首次导入与已导入冷启动分别报告。
- Android / Windows 尽力进行原生运行与测量，缺失工具可安装；无法执行的验证明确记录，不用 Linux 或单元测试冒充。
- 自动恢复须由用户选择；保存首页条件/位置及帖子阅读位置，处理删除、过期、异常快照与进程终止。
- 明确小说字数与书评文本长度的区别，修正新增数据和存量数据，避免将书评长度纳入小说字数榜。
- 书源放最后，先调查导航页、最新地址、搜索与下载接口及 GitHub 参考；登录、验证码或付费门槛不能假装成功。
- 完成后清理本任务生成的临时库、日志、截图、构建/模拟器测试残留；保留必要的自动回归测试源码和结果文档。

## 执行顺序

1. 检查启动调用链、数据库大小和查询计划，建立可复现基线。
2. 优化首屏与数据库/资源体积，验证数据完整性与迁移，提交。
3. 实现阅读会话持久化与启动恢复提示，覆盖首页和帖子，提交。
4. 统一字数口径，修复采集/导入/聚合/存量榜单，提交。
5. 调研并接入尚香书苑和搜书吧，提供搜索与选择保存位置下载，提交。
6. 运行聚焦测试、完整回归、静态分析及可用的原生验收，更新交接文档，清理并提交。
